# Map the current state

You have insights, needs and a pain point register describing what users experience. What you do not yet have is a picture of the whole experience — where the friction is, what is happening backstage, and how the pieces connect. This capability builds that picture.

You start with the evidence repository, your personas, the pain point register, insights from synthesis, and stakeholder input on the backstage processes. You finish with an as-is user journey map and an as-is service blueprint, each entry tracing back to an evidence item.

---

## Key artefacts

| Activity | UX artefact | When it is worth doing |
|---|---|---|
| Agree the journey scope: which persona, which journey, which stages are in and which are not | Journey scope note | Before any mapping begins. A map with no agreed scope tends to cover everything and explain nothing |
| Map the as-is user journey: stages, actions, thoughts, emotions, pain points, moments of highest friction | As-is user journey map | You need to show the current experience to stakeholders, or the team disagrees on what it looks like |
| Add the backstage layer: the processes, systems and people that shape what the user experiences | As-is service blueprint | You are working on a service with a significant backstage that affects user outcomes |
| Validate the maps with users and stakeholders before treating them as agreed | Validated maps | Always, before the maps are used to support decisions |
| Note what the maps do not cover, so gaps are visible and not forgotten | Gaps note | Always. Named gaps are more useful than blank spaces |

---

## What can agents do?

**AG-02 Research Synthesis** drafts the as-is journey map and service blueprint from filed evidence, citing an evidence item ID on every entry, and flags entries where no evidence is available.

**AG-04 Design Organiser** formats and lays out the maps in a readable structure for review and sharing.

Neither agent adds stages, pain points or backstage processes without a source, or decides which persona or journey to map.

---

> 💡 **Tips**
>
> **Start with the journey scope, not the stages.** Agree which persona and which journey before any drafting begins.
>
