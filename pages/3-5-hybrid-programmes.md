# 3.5 Hybrid programmes

| **SECTION SUMMARY** | *Applying delivery paths at increment level within a mixed programme* |
|---------------------|-----------------------------------------------------------------------|

A programme may combine greenfield, brownfield, integration and modernisation work. The visual should therefore be applied at increment level. One programme may create a new customer journey, enhance an existing service, modernise a component and integrate a reusable capability at the same time. Each increment should record its path, starting context, reused artefacts, applicable activities, human approvals and rollback route so that programme-level labels do not hide different delivery risks.

## Execution rules

The same governed Agentic PDLC applies across project types. For hybrid programmes, the key discipline is applying the correct path classification at the level of each bounded increment rather than at programme level. A programme-wide label of "greenfield" or "brownfield" can obscure significantly different delivery risks within individual increments. Each increment should be classified, planned and governed according to its own type.
