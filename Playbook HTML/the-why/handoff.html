Proposal Handoff

Every time work crosses a boundary — between phases, between people, or between a person and an agent — something can go missing. The context behind a decision. The reason a direction was ruled out. This capability makes those crossings deliberate, so the person or agent on the other side can pick up the work without reinventing it.

Key artefacts

Activity UX artefact When it is worth doing
Identify which direction the handoff runs and what the recipient needs Handoff decision log entry Before any handoff — naming the direction shapes what goes in the package
Package the artefacts, decisions, rationale, open questions and next actions for a colleague; brief the recipient directly if the context is complex Handoff package (human-to-human) At phase gates, at team boundaries, or any time work passes from one person to another
Write the task scope, name the approved context sources, state the constraints and specify the output format and reviewer for a task you are delegating to an agent Agent task brief Before giving any task to an agent
Review what the agent returns: check its output against the brief, read the evidence IDs and confidence levels, and note what it did not do Reviewed output Every time an agent delivers a result
Agree the output structure the sending agent will use so the receiving agent can work from it without interpretation Agent-to-agent output structure Before a multi-agent workflow begins
Log every handoff: who handed off what, to whom, when and under what conditions Decision log entry Always

What can agents do?

AG-04 Design Organiser assembles completed work into a handoff package, formats documents for transfer and prepares stakeholder share-out packs to an approved template.

AG-01 Evidence Librarian logs each handoff decision with its rationale, the direction, the parties involved and the conditions that applied.

Neither agent decides what is complete enough to hand off, or hands off any material without a person confirming readiness.

💡 Tips

A fuzzy scope will produce a fuzzy result. If an agent can interpret a task in more than one way, it will. Write the scope until the task is unambiguous. Between agent to human, the handoff must be explicitly in saying what was done and not done. "I drafted the persona from the evidence. I did not check whether all sessions had been cleared for use" is more useful for human to carry on the incomplete task.
