Stage 03: Contextualise

What you are responsible for

You provide codebase, configuration, test and implementation context to support downstream agent-enabled delivery.

Context package

Have codebase, configuration, test and implementation details been accurately captured? Are there gaps that could block downstream agents?

Stage 05: Design experience and architecture

What you are responsible for

You provide implementation insight and identify feasibility, reuse, dependency and migration implications.

Context package

Does the context package reflect implementation constraints, reuse opportunities and feasibility considerations identified during design?

Technical specification

Is the specification implementable given the current codebase and engineering constraints? Are migration, dependency or feasibility issues flagged?

Stage 06: Create backlog & specs

What you are responsible for

You confirm specifications are feasible and reflect the codebase and engineering constraints.

Technical specification

Does the specification accurately reflect the codebase, engineering constraints and feasibility considerations? Are implementation gaps or risks surfaced?

Stage 07: Plan and decompose

What you are responsible for

You confirm tasks, dependencies and verification steps are executable.

Implementation plan

Are tasks executable against the actual codebase and engineering constraints? Are dependencies, verification steps and integration considerations accounted for?

Stage 08: Build

What you are responsible for

You own implementation quality and review agent-generated code and unit tests.

Implementation output

Does the agent-generated code meet quality and specification standards? Are unit tests correct and coverage adequate? Are deviations from the specification identified and resolved?

Stage 09: Validate

What you are responsible for

You investigate defects and implement remediation based on validation findings.

API test results

Are defects correctly described and reproducible? Have root causes been identified and remediation implemented?

Functional test results

Are defects correctly described and reproducible? Is remediation complete and verified against acceptance criteria?

Stage 10: Release

What you are responsible for

You confirm the release candidate and implementation-specific deployment considerations are ready.

Stage 11: Operate and improve

What you are responsible for

You investigate production issues and feed code-level learning into subsequent increments.

Context package

Have production issues and code-level learning been correctly captured for subsequent increments? Are recurring issues and root causes reflected?

A.12
