The roles shown are indicative and should be tailored to the scope, complexity and risk of each increment. They are not intended to define a fixed squad structure or RACI.

The mapping is informed by recognised practices including the Scrum Guide for product ownership and backlog accountability, ISO 9241-210 for human-centred design, the Microsoft Azure Well-Architected Framework for architecture, reliability and operational excellence, and Microsoft Secure DevOps and the NIST Secure Software Development Framework (SSDF) for integrating security throughout the development lifecycle. These practices have been adapted to the Agentic PDLC lifecycle and the core product squad roles defined in this playbook.
