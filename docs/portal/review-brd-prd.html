Review BRD or PRD

What this checklist is for

Use this checklist whenever you receive an agent-generated BRD or PRD for review. It helps you quickly identify whether the document is complete, coherent and ready for the next phase — or whether it needs to go back to the agent for revision before you sign off.

How to use it

Work through each item in sequence. Check the box when you are satisfied. Leave it unchecked if something is missing, unclear or contradictory — add a comment in the document and return it for rework. You do not need every box checked to proceed, but you should be able to justify any gap before signing off.
